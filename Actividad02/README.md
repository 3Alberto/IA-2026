# El Mundo del Wumpus

Este repositorio contiene la configuración, documentación y las pruebas de ejecución de distintos agentes resolviendo el entorno del Mundo del Wumpus en un tablero personalizado.

## Archivos del Proyecto

### Entorno y Configuración
* **`mi_cueva_4x4.yaml`**: Archivo de configuración que define la estructura de la cueva modificada en una cuadrícula de 4x4.
* **`DiagramaDeMiCueva.jpg`**: Diagrama ilustrativo de la cueva. Indica visualmente las posiciones iniciales del agente, el Wumpus, los pozos (*pits*) y la ubicación del oro.

### Documentación
* **`Reporte.txt`**: Breve reporte analítico sobre el proyecto y el desempeño de los agentes.
